## 1. The project in one paragraph

A personal **theme studio for KOReader**: design, preview and apply the complete look of
the user's e-readers from a desktop/web tool, with **SimpleUI, Bookshelf and KOReader
staying the renderers** (the studio writes what they already read). Plus an
**upstream checker** that warns when a SimpleUI/Bookshelf/KOReader update breaks what the
studio produces, and a **separate loader plugin for custom SimpleUI modules** (weather,
sports first). Decided: a studio around the existing tools, NOT a replacement UI plugin.
**Focus SimpleUI over Bookshelf** for custom modules.

## 3. Emulator facts (hard-won — don't rediscover)

- No prebuilt macOS KOReader exists. Build prerequisites = brew list in
  `koreader/doc/Building.md` **plus `wget`**. Do NOT install optional `ccache` (drags in
  an LLVM source build, 1–2 h on macOS 14). Put GNU getopt/make/findutils/coreutils/
  util-linux first on PATH for `./kodev`.
- Screen: `EMULATE_READER_W/H/DPI`, `EMULATE_READER_FORCE_PORTRAIT=1`. Colorsoft = 1264×1680 @ 300.
- Headless: `SDL_VIDEO_DRIVER=offscreen` (SDL3 here has cocoa/offscreen/dummy). Offscreen
  takes 1264×1680 directly. The cocoa window on a Retina Mac doubles pixels and macOS
  clamps height — if you need a visible window, request 632×840.
- Settings live in the emulator folder; `KO_HOME=<dir>` relocates them → per-device
  profiles. A "Paperwhite" profile = different W/H/DPI + its own KO_HOME (grayscale needs
  `color_rendering=false`).
- Screenshots: `Screen:shot(path)` from Lua; F8 in a window. Userpatches in
  `patches/` run at priority 2 ("late") after the UI is up — the automation hook.
- Applying a SimpleUI icon pack from outside = `require("features/sui_style").applyPack(dir)`
  (exactly what Solar's plugin does). Solar install itself = plain file copies.
- Plugins log "name in _meta.lua is deprecated" — harmless.
- Capture currently only shows the start screen. Scripted navigation (open book, open
  Bookshelf, open menus) is unbuilt.

## 4. Device + user facts

- **Kindle Colorsoft SE** (jailbroken, Véra/KPM, KOReader 2026.07.1): the primary target.
  Installed there: Storefront, `cwngsync` (Calibre-Web-NextGen sync, paired),
  SimpleUI, Bookshelf, Solar icon pack, Icon Pack Changer (`iconschanger.koplugin`).
  Sleep screens: `koreader/screensavers/` with transparent overlays, "No fill",
  cycle in order. Books are pulled via OPDS from `https://books.elatedpanda.lol/opds`
  (CWNG library folder OFF by choice — don't re-suggest).
- **USB from the Mac**: MTP only. Kindle shows on USB only from the stock home screen
  (exit KOReader first) and drops off after every MTP session → push in ONE libmtp
  session. Single-session C pushers (`push_plugin.c` for folders, `push_file.c` for files,
  `swap_file.c` copy-then-delete) were built against brew `libmtp` in the strem
  scratchpad and are gone — rebuild them (~80 lines each). OpenMTP is installed for manual
  drags. Don't push right before a 40 s hard restart (unsynced writes can be lost).
- Android phone (KOReader) and future grayscale devices: multi-device targets, specs
  unknown. Xteink X4 Pro runs CrossInk → out of scope for theming.
- Icon Pack Changer's "Restore" deletes every .svg in `koreader/icons/` — one pack at a time.

## 5. Requirements captured so far (draft — owner is still refining)

**Devices:** Colorsoft primary; Android KOReader; future grayscale; X4 out of scope.

**What the studio edits**
- SimpleUI: home modules + order + **per-module size/scale** (module/label scale,
  linked scaling), **wallpaper**; bars (nav tabs ≤5, top/title/quick-settings bars, their
  sizes and icon/label scales); quick actions (plugin/system/folder/collection) + icons;
  style (fonts, font scale, icon packs, per-slot system icons); quotes, collections,
  streaks, goals, TBR. SimpleUI exposes ~280 `simpleui_*` keys — rule: **every key is
  editable**, schema generated from the plugin's own keys.
- Bookshelf: shelves (sources, filters, sort, labels, icons, colours); **wallpaper**
  (day/night/full), **planks**, **ornaments** (packs on/off, size, padding, mirror,
  anchor, height), colour themes, theme packs as a unit; covers/spines (grid/list/spines,
  corners, shadows, sizes, spine rows); modules/micro-modules (which, sizing, borders,
  backgrounds, footer); **start menu** (position + entries); top panel + detail-card templates.
- KOReader: icons (102 slots), fonts, sleep screens, status bar/footer presets, style
  tweaks, gestures/tap zones.
- Cross-cutting: **icon mapping across all three layers** as one task (slot grid with
  screen crops; Iconify/Solar/own SVGs; AI matching by meaning; stroke/colour
  normalisation; one export → `koreader/icons/*.svg` + SimpleUI `pack.lua` + custom icons).

**Capabilities:** pixel-exact emulator previews, per-device profiles side by side, e-ink
simulation filter, scripted navigation to capture every screen; visual editor over the
schema with live preview; theme as versioned config (history/diff/rollback); theme bundles
installed/rolled back as a unit; vibe-to-theme (description/moodboard → palette, fonts,
icon style, wallpaper/plank/ornament/screensaver art; AI previews + critiques its own
output for e-ink); asset pipelines (screensaver cut-out/fit/preview, wallpapers, planks,
SVG ornaments per Bookshelf's rules); push to device (USB now, SSH plugin if it works);
**upstream checker** (watch releases; diff settings keys, icon slots, patch hooks vs what
the studio writes; prove in the emulator; propose migrations).

**Custom SimpleUI modules:** via a **separate loader plugin** (SimpleUI's official
`Registry.register(module)` hook in `modules/moduleregistry.lua`; maintainer explicitly
rejects dropping files inside SimpleUI's folder). Module contract: `id`, `name`,
`enabled_key`/`default_on`, `build(w, ctx)`, `getHeight(ctx)`, `getMenuItems()`,
`text_elems` → modules get SimpleUI's sizing/fonts/colours/Arrange for free.
Existing frame to reuse or copy: `omer-faruq/simpleui_ext.koplugin` (75★, auto-discovers
`module_*.lua`). First modules: **weather** (Open-Meteo, no key) and **sports**
(ESPN public scoreboard / TheSportsDB) — both need fetch-when-online + file cache +
"last updated" when offline. No SimpleUI weather module exists today.

**Out of scope:** context-aware looks (per-book themes, time rules, generated sleep screens).

**Constraints:** SimpleUI MIT, Bookshelf AGPL (fine for personal use; mixing Bookshelf code
makes the result AGPL); both plugins ship weekly (80 / 100+ commits in 5 weeks) so the
checker is mandatory; Oracle (ARM) hosts any server piece.
