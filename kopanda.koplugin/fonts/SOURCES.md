IBM Plex has no `OFL.txt`; its licence file is `LICENSE.txt` (the OFL 1.1 text with IBM's reserved
font name), shipped here as `ibm-plex-sans/OFL.txt`.

Bricolage Grotesque's static set in `fonts/ttf/` carries no optical-size label; it is taken to be the
14pt optical size, inferred from advance widths, not documented upstream. Newsreader ships static
instances at 6pt, 16pt and 72pt only; the 16pt one is used at every size.

Big Shoulders was reorganised upstream into `Big-Shoulders/`, `Big-Shoulders-Inline/` and
`Big-Shoulders-Stencil/`; the head commit still ships the Display optical size as static TTFs, and
the file used is the plain (not Inline, Stencil or SC) Display Black.

Baloo 2's repository holds sources and TTX dumps only, no font binaries; the file is the one built
upstream in the `1.640` release's `Baloo2_1.640.zip` (the Devanagari-and-Latin Baloo 2, hinted with
ttfautohint), whose tag is the commit named. The default branch's head,
`bfe79a8276ea9c1a2005f645bbeb888eef4b54d5`, differs from that tag only in `README.md`, and its
`OFL.txt` is the one shipped.

Nunito ships only variable fonts (`fonts/variable/`). The three files are instances of
`Nunito[ital,wght].ttf` (SHA-256 `a37935a46508b065a4217678b2b4d1c73f47ab6050e8ba355dea778c3a49b0d0`),
made with fontTools 4.67.0 as
`python3 -I -m fontTools.varLib.instancer --update-name-table -o <file> 'Nunito[ital,wght].ttf' ital=<0|1> wght=<weight>`
with the axis values in each row; the hashes are of the instanced files. The combined `ital,wght`
font is used rather than `Nunito-Italic[wght].ttf` because its italic instance gets the PostScript
name `Nunito-SemiBoldItalic`, where the italic-only font gives `NunitoItalic-SemiBoldItalic`; their
outlines differ by at most one unit.
